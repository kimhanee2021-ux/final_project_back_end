# OpenAI 한국어 낭독 연결

의도 해석은 기존 Gemini API 및 공통 게임 검증을 유지합니다. 낭독만 서버의 OpenAI Realtime API로 연결합니다. 저장된 요약을 새로 생성하거나 수정하지 않습니다. 브라우저 음성 인식도 유지합니다.

## 활성화

이 문서 자체에는 실제 API 키를 입력하지 마세요. 실제 설정 파일은 백엔드 프로젝트 루트의 .env입니다.

백엔드 `.env`에 아래 항목을 추가한 뒤 백엔드를 다시 시작합니다. 키를 프런트엔드 환경 변수나 소스 코드, 채팅에 넣지 마세요.

```dotenv
OPENAI_API_KEY=발급받은_API_키
OPENAI_SPEECH_MODEL=gpt-realtime-2.1-mini
OPENAI_SPEECH_VOICE=marin
```

OpenAI API 사용 권한과 결제가 별도로 필요합니다. ChatGPT 구독 인증으로 대체되지 않습니다. 키가 없으면 `SPEECH_NOT_CONFIGURED` 안내와 화면의 기존 요약을 표시합니다. 기존 브라우저 목소리로 자동 전환하지 않습니다.

## 재생과 발음

- `POST /api/games/news/speech`에 `{ "text": "읽을 문장" }`을 보내면 24 kHz, 16-bit, mono WAV를 반환합니다. 키와 모델 선택은 서버에만 있습니다.
- Realtime에는 마이크 음성이나 검색 카탈로그를 보내지 않습니다. 입력은 낭독 대본이며 도구나 의도 해석을 연결하지 않습니다. 대본만 그대로 읽도록 별도 지침을 적용합니다.
- 한국어 발음 안내와 게임명 발음 사전을 낭독에만 적용합니다. Dota 2 → 도타 투, Counter-Strike 2 → 카운터 스트라이크 투, Team Fortress 2 → 팀 포트리스 투. 다른 게임은 모델의 한국어 고유명사 발음 지침을 따릅니다. 날짜는 한국어 연·월·일 형식입니다. 실제 목소리 품질은 키 활성화 후 청취 확인이 필요합니다.
- 중지는 브라우저 요청과 재생을 취소하고 늦은 응답도 무시합니다. 이미 OpenAI에서 진행 중인 생성은 서버의 제한 시간 이내에 끝날 수 있습니다. 중지가 이미 발생한 API 비용을 되돌리지는 않습니다.
- 다시 듣기는 준비된 요약 음성을 브라우저 메모리에서 재사용합니다. 게임 변경·수동 필터·화면 이동은 기억한 음성을 지웁니다. 서버는 최대 32개/16 MB, 1시간의 메모리 캐시를 사용하며 DB나 파일에 음성을 저장하지 않습니다.
- 2,400자 제한, 동시 생성 2건, IP당 분당 신규 생성 10건, 서버당 UTC 하루 60,000자 한도를 둡니다. 서버 재시작 시 메모리 한도와 캐시는 초기화됩니다. 공개 대규모 배포 시 공유 저장소의 사용량 제한이 필요합니다.

## 검증 범위

로컬 테스트에서 발음용 문자열, 날짜, PCM/WAV 조립, API 오류, 캐시, 중지, 늦은 응답, 자동 재생 제한, 다시 듣기를 확인합니다. API 키를 설정하지 않은 상태에서는 실제 OpenAI 호출과 음질 평가를 수행하지 않습니다.

공식 문서: https://developers.openai.com/api/docs/guides/realtime-conversations

기존 Speech API의 TTS 모델은 2027-01-06 종료 예정이므로 새 연동에는 권장 Realtime 모델을 사용합니다: https://developers.openai.com/api/docs/guides/text-to-speech
